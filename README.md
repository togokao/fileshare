# FileShare

簡易檔案分享網頁：上傳檔案後，所有人都能在頁面上看到並下載；**檔案被下載一次後就會自動刪除**。

## 執行

需要 Node.js 18 以上，沒有任何第三方套件。

```bash
PASSWORD=你的密碼 npm start
# 開啟 http://localhost:3000，輸入密碼登入
```

如果沒有設定 `PASSWORD`，伺服器啟動時會隨機產生一組密碼並顯示在終端機上（每次重啟都不同）。

## 設定（環境變數）

| 變數 | 預設 | 說明 |
| --- | --- | --- |
| `PASSWORD` | 隨機產生 | 登入密碼 |
| `SESSION_HOURS` | `168` | 登入有效時間（小時），預設 7 天 |
| `PORT` | `3000` | 伺服器埠號 |
| `MAX_SIZE_MB` | `100` | 單檔大小上限（MB） |
| `UPLOAD_DIR` | `./uploads` | 檔案儲存位置 |

## API

- `POST /api/login` — 登入，body 為 `{"password": "..."}`，成功後設定 cookie
- `POST /api/logout` — 登出

以下 API 都需要先登入：

- `GET /api/files` — 列出目前可下載的檔案
- `POST /api/upload` — 上傳檔案，request body 為檔案內容，檔名放在 `X-Filename` header（URL 編碼）
- `GET /api/download/:id` — 下載檔案，下載後檔案即刪除

## 說明

- 下載請求一進來，檔案就會立刻從列表移除，所以同一個檔案只有一個人能下載到。
- 傳輸結束（完成或中斷）後，伺服器會刪除磁碟上的檔案。
- 檔案資訊存在 `uploads/` 中，伺服器重啟後尚未下載的檔案仍然存在。
- 所有人共用同一組密碼，只有登入後才能看到、上傳和下載檔案。
- 同一個 IP 密碼錯誤 10 次會被鎖 15 分鐘。
- 更改密碼後重啟伺服器，所有人都會被登出。
- 伺服器本身是 HTTP，若要在公開網路上使用，請放在 HTTPS 反向代理（例如 Nginx、Caddy）後面，避免密碼被竊聽。
